What it saves

78% fewer tokens a question than sending the whole conversation: 4,809 against 22,069, on the same 382 questions, answered by the same model.

Models bill input by the token, so the memory part of every call costs 78% less. At an example price of $1.00 per million input tokens, 1,000 questions cost $4.81 of context with memwise and $22.07 with the whole conversation. Use your model's price: the saving is the same share.

Building the memory is a one-off extra: one extraction call per chat session per person, about 3,500 tokens each, 1.9 million for all 10 conversations. Counted in, memwise used 73% fewer tokens over the whole benchmark than sending the whole conversation with every question.

Published for reference: Mem0 reports 92.5 with 6,956 tokens a query. memwise uses 30% fewer tokens and scores 2.8 points lower. Mem0 used its own models and grader, so this is not a controlled comparison.
